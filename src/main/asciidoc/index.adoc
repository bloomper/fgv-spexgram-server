[[introduction]]
== Introduction

Spexgram Server is the backend of Spexgram, FGV's archive of photos and short videos, kept in Immich behind it.

The purpose of this documentation is to provide details on how to develop within Spexgram Server and how to integrate Spexgram Server into another application, e.g. a web application.
